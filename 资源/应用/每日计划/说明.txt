■ 界面功能
· 制定：模板一键套用、AI 生成计划、按上一级计划拆解、习惯任务铺进今天
· 规划：五个周期（日/周/月/季/年）分组管理，目标主线链、未完成一键顺延
· 执行：独立计时器、到点提醒、写进手机日程
· 回顾：日终复盘、KPI、热力图、趋势图、时段效率排行、老赖榜，可导出 CSV / Markdown


■ 具体细节
· 角色在聊天室直接发「今日计划播报」「该做这件事了」卡片
· 聊天输入框 + 号面板三入口：看今日计划 / 记一笔 / 开始计时
· 六项聊天工具：读计划、加任务、勾完成、删任务、整体重写、管习惯
· 到点提醒可带角色动作，让 TA 在聊天室开口提醒你
· 关键节点可写角色记忆（可关闭），复盘能让角色引用你的真实数据
· 计时开始 / 结束 / 复盘后用语音念一句
· 子清单：小项全勾自动勾上整条，取消小项自动退回
· 重要度 1~3：AI 重排时保重要、先砍次要
· 量化目标：任务行显示进度条，勾完成自动补满
· 模板变量：模板里写 {{数量}}，套用时弹窗让你填
· 任务依赖：前置没做完会提示「等『XX』做完才能开始」


■ 使用前须知
· 需要你先在「设置 → API 设置」配好自己的 LLM API，本产品不内置模型服务
· 所有数据存在浏览器本地（IndexedDB），请定期备份导出，清浏览器数据会丢档
· 提醒 / 语音 / 日程同步
