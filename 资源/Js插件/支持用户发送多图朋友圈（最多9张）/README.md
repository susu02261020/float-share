# Float 朋友圈多图 v1.0.1

**作者：Auren&Chloe**

这是一个不修改 Float 核心源码的 Chat Plugin，为原生朋友圈增加最多 9 张图片的发布、九宫格展示与多图视觉提交能力。

## 安装

在 Float 的插件管理中导入 `float-moments-multi-image-v1.0.1.js` 并启用。

## 功能

- 最多 9 张图片。
- 可一次多选，也可继续追加。
- 发布前可以删除单张图片。
- 编辑页使用三列、统一正方形预览。
- 发布后使用九宫格；1 / 2 / 4 / 5–9 张会按现有朋友圈布局显示。
- 点击图片可查看大图。
- Moments 的模型请求会包含该朋友圈的全部图片。
- 原有单图朋友圈不受影响。

## 模型看图

插件会在 `purpose === "moments"` 的 `llm.request` 阶段补齐全部图片。
如果 Float 的“图片识别”关闭，或当前 API / 模型本身不支持视觉，底层仍会按 Float 原规则降级，因此模型不会真正读取图片内容。

## 数据与卸载

第一张图仍由 Float 原生 `photoUrl` 管理；第 2–9 张图写入 Float 现有图片资产库，`postId -> extraAssetIds` 绑定保存在插件私有存储。

**禁用插件不会删除绑定。**
**卸载插件会删除插件私有绑定。**

因此，只要已有朋友圈依赖第 2–9 张图片，不建议直接卸载。卸载后帖子会退回原生单图显示。

## 兼容性

已验证：

- 原版 Float 当前 `main`
- Chat Plugin API v1
- 2026-10-07

本插件有一部分实现需要当前朋友圈 DOM class / aria 结构和 IndexedDB 名称，因此它不是“只依赖公开 API”的永久兼容插件。未来 Float 若重构朋友圈页面或数据库，需要更新插件。

## 升级说明

公开版继续沿用测试版插件 ID `auren.moments-multi-image-temp`，这是有意为之：这样从 v0.1.x / v1.0.0 更新到 v1.0.1 时，既有多图朋友圈绑定不会因为插件 ID 改变而丢失。
